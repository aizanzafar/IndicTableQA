## 📌 Overview

**IndicTableQA** is a multilingual benchmark designed to evaluate **Table Question Answering (Table QA)** capabilities of Large Language Models (LLMs) across **Indian languages**.

The benchmark focuses on:
- Structured reasoning over tables
- Multilingual understanding
- Logical and numerical reasoning in low-resource settings

We evaluate multiple state-of-the-art LLMs in a **zero-shot setting**, highlighting challenges in multilingual table reasoning.

---

## 🌍 Supported Languages

- Hindi (HI)
- Bengali (BN)
- Telugu (TE)
- Tamil (TA)
- English (EN)

---

## 🤖 Models Evaluated

We evaluate several recent LLMs including:

- Qwen3-8B (think / no-think)
- Qwen3-14B (think / no-think)
- Phi-4
- Gemma-3-12B
- OpenHathi-7B
- Sarvam-M

---

## 📈 Evaluation Metrics

- Cell F1 (Primary Metric)
- Row F1
- Column F1
- Parse Success Rate
